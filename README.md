# AdventSec Issues

Repositorio público para reportar errores, proponer mejoras y compartir sugerencias sobre **AdventSec**, una plataforma educativa para practicar ciberseguridad con un calendario de 25 retos y demos públicas, disponible en español e inglés.

Este repositorio centraliza las incidencias de la plataforma. No contiene su código fuente ni las soluciones de los retos.

## 🐛 Reportar un problema

Si algo no funciona como esperabas, abre una incidencia en la pestaña **Issues**.

Antes de publicarla, revisa si alguien ya ha reportado el mismo problema. Si existe una incidencia relacionada, puedes añadir información allí.

Incluye lo siguiente para facilitar su revisión:

- **Descripción:** qué problema encontraste.
- **Pasos para reproducirlo:** qué hiciste antes de que ocurriera.
- **Resultado esperado:** qué debería haber pasado.
- **Resultado obtenido:** qué pasó realmente.
- **Contexto:** página o día del reto, idioma, navegador y dispositivo.
- **Capturas:** si ayudan a entender el problema, ocultando cualquier información privada y las respuestas de los retos.

Usa un título concreto, por ejemplo: `El menú móvil no se cierra al seleccionar una página`.

## 💡 Proponer una mejora

También puedes abrir una incidencia para sugerir nuevas funciones, mejoras de accesibilidad, ajustes de diseño o correcciones de textos y traducciones.

Explica qué necesidad resolvería tu propuesta y, si es posible, incluye un ejemplo de cómo te gustaría que funcionara.

## 🚩 Evita los spoilers

Para conservar la experiencia de quienes están resolviendo los retos:

- No publiques flags, respuestas ni soluciones completas.
- Evita capturas o archivos que revelen cómo resolver un reto.
- Si necesitas compartir una solución para explicar un fallo, envíala por correo.

## 🔒 Comunicar una vulnerabilidad

Si detectas un problema de seguridad en la plataforma, comunícalo de forma privada a **[marcvspt@gmail.com](mailto:marcvspt@gmail.com)**.

Describe el problema, los pasos mínimos para reproducirlo y su posible impacto. Evita publicar detalles sensibles en una incidencia pública o acceder a datos de otras personas.

## 🤝 Participación

Mantén un trato respetuoso y aporta información relacionada con la incidencia. No publiques contraseñas, tokens, cookies de sesión ni datos personales.

Puedes reportar problemas y enviar sugerencias en **español o inglés**.
